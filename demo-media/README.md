# Downloadable demo videos

These finished videos are included in Git. After cloning, open an MP4 directly in your video player; no app server or API key is needed.

Start with **english-3-second-pauses** for the revised voice and shorter pauses. **hinglish** includes Hinglish and earlier dual-language versions. For dual-language files, choose the audio track in a player that supports it (for example VLC).

The recorded app tours, captions, and chapter list used by `/demo/videos` are in `apps/web/public/demo-videos/`.
